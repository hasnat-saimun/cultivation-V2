# Cultivation V2 - User Guide (Teacher Admin)

This guide is for Teacher Admin users who manage attendance and marks entry.

---

## Quick Access
- Attendance Management
- Marks Entry
- Result viewing (assigned classes)

---

## Sidebar Menu
- Cultivation Admin
- Marks Entry
	- Marks Entry
- Attendance Management
	- Mark Attendance
	- Daily Report
	- Monthly Sheet

---

## Attendance
- Mark Attendance: Attendance -> Mark Attendance
- Daily Report: Attendance -> Daily Report
- Monthly Sheet: Attendance -> Monthly Sheet

Tips:
- Use the assigned class and section for attendance.
- Export reports as CSV when needed.

---

## Marks Entry
- Navigate: Results -> Marks Entry
- Select exam, class, session, and section.
- Use only assigned subjects for your profile.

Tips:
- If subjects do not load, re-select class and section.
- Save frequently when entering large sets of marks.

---

## Printing Tips
- Use Chrome or Edge.
- Enable Background graphics in print settings.

---

## Troubleshooting
- Missing subjects: Contact admin to assign subjects.
- Access denied: Check your role permissions.

---

## Support
Contact your General Admin for access or profile updates.
