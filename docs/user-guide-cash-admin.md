## Fees and Payments
- Record payments and receipts.
- Verify student fee status before finalizing.
- Use filters for class/session where available.

## Reports

- Export reports for audit or sharing.

- Enable Background graphics in print settings.

- Report mismatch: Re-check date range and filters.
