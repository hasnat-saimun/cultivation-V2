## Student Fees Access Rules
- Teacher Admin can access fee records only for assigned class/section students.
- Assignment is taken from teacher profile and class/section assignment data.
- Fee pages show an info panel with your current assigned classes and sections.

If you cannot find a student in fee pages:
- Check class and section filters.
- Contact General Admin to update your class/section assignment.

---

## Student Fees Collection
Navigate: Student Fees -> Fees Collection

What you can do:
- Search student by class/session/section/name/roll.
- Select student and collect monthly fees.
- Collect partial amounts (system keeps due amount).
- Existing monthly fee records are shown for selected student.

Important:
- Setup Amount = total monthly fee setup.
- Collected Amount = total collected so far.
- Due Amount = remaining amount.

---

## Dues Dashboard
Navigate: Student Fees -> Dues Dashboard

What you can do:
- View due/partial fee records for assigned students.
- Filter by class, session, section, fee month, and search text.
- Open Collect Due action to receive only the remaining due amount.

---

## Generate Student Fee Report
Navigate: Student Fees -> Generate Report

Steps:
1. Find and select the student.
2. Choose report basis:
	- Daily
	- Monthly
	- Custom Range
3. Use quick presets if needed:
	- Today
	- This Month
	- Last 30 Days
4. Generate and print report.

---

## Single Invoice List
Navigate: Student Fees -> Single Invoice

What you can do:
- View fee entries for assigned students.
- Open invoice, details, and due-related actions.

Note:
- Full record edit is restricted for Teacher Admin.
- Use due collection workflow for payment updates.

---

## Attendance
- Mark Attendance: Attendance -> Mark Attendance
- Daily Report: Attendance -> Daily Report
- Monthly Sheet: Attendance -> Monthly Sheet

Tips:
- Use the assigned class and section for attendance.
- Export reports as CSV when needed.

---

## Marks Entry
- Navigate: Results -> Marks Entry
- Select exam, class, session, and section.
- Use only assigned subjects/classes for your profile.

Tips:
- If subjects do not load, re-select class and section.
- Save frequently when entering large sets of marks.

---

## Printing Tips
- Use Chrome or Edge.
- Enable Background graphics in print settings.

---

## Troubleshooting
- Missing subjects: Contact admin to assign subjects.
- Student not visible in fees page: Check assigned class/section and filters.
- Access denied: Check your role permissions and assignment scope.

---

## Support
