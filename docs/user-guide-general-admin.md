This guide covers the workflows and responsibilities for General Admin users.

---

## Quick Access
- Dashboard: Overall statistics and shortcuts
- Admission: Students, promotions, bulk photo uploads
- Teachers/Staff: Profiles, bulk updates
- Results: Marks entry, transcripts, archives
- Settings: Institute configuration, logo, signatures

## Student Management
- Add new admission from Admission -> New Admission.
- Search and filter students by session, class, section, department.
- Bulk update student data: Admission -> Bulk Details Update.
- Bulk student ID cards: Admission -> Bulk ID Cards.

## Teacher and Staff Management
- Add or edit teacher/staff profiles.
- Use bulk update tools for large edits.
- Upload photos in bulk when required.

## Results and Certificates
- Add marks and generate transcripts.
- Use Result Archive for historical records.
- Generate testimonials and transfer certificates from Student List.

## Attendance
- View daily and monthly reports.
- Export attendance reports as needed.

## Institute Settings
- Set institute name, address, email, phone.
- Upload logo and principal signature.
- Review SMS settings if enabled (not available on demo hosts).

---

## Printing Tips
- Use Chrome or Edge for printing.
- Enable Background graphics in print settings.
- For ID cards, confirm A4 paper and margins before print.

---

## Troubleshooting
- Missing logo or signature: Update institute configuration.
- Slow list pages: Apply filters before bulk editing.
- Print layout issues: Confirm browser print margins and scale.

---

## Support
Contact your system administrator for access or configuration changes.
